# iPad 使用与开局树同步

本次安装：2026-10-02，iPad Air（第 5 代），应用「神之一手」。已安装并传入 9 棵树，12 个数据文件读回 SHA-256 校验一致。用户已信任开发者签名，设备启动命令已成功打开应用（开局树构建模式）。

## 使用

开局树在平板本地保存，可离线修改、增加和删除。电脑与平板目前不会自动云同步。

## 过几天回传

把 iPad 连接回这台电脑，并请求同步。同步前备份两端，再以本次出发副本比对变化，把平板新增、修改、删除的树及分枝带回电脑；若电脑也改过同一棵树，先检查冲突，不直接覆盖。

出发副本：`.build/iPadTransfer/2026-10-02/OpeningTrees`。
同目录 `baseline-sha256.json` 用于检查电脑端是否也发生变化，`QipanChess-全部开局树.json` 为可导入的便携副本。

也可在 iPad 的开局树面板选择「导出开局树 → 导出全部开局树」，通过系统分享保存到“文件”或 AirDrop 回电脑，再在电脑选择「导入开局树」。同 ID 树替换前应用会备份，分枝删除记录随树保留。但整个树被删除后不会出现在普通导出中，因此需要同步整树删除时优先使用上面的有线回传与基线比对。
