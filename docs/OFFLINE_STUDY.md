# 棋局记录、复盘与个人开局树

主界面提供 **自由分析、与 AI 对弈、开局树构建**。每步自动评价；自由分析直接浏览当前路线附近的分枝，构建模式展示完整的向上生长画布。旧开局教练与固定训练课程已移除。

## 开局树文件与手动同步

在“我的开局”面板选择“导出开局树”，可导出当前树或全部树。请先保存正在研究的路线和备注。iPad／iPhone 会打开系统分享面板，可选择隔空投送或存储到“文件”；Mac 会打开文件保存窗口。文件为带格式版本的 JSON，包含路线、树名、执棋方、备注、主线、隐藏／删除状态和已有节点评分。

在接收设备的同一面板选择“导入开局树”，选择收到的 JSON 文件。已有相同树 ID 时需确认替换：使用文件中的完整版本，不自动合并两端修改；替换前将本机原文件备份到开局树目录的 `ImportBackups` 子目录。其他开局树保留。导入的树重启后保留原有结构，不参与启动时的首着自动合并。

这是双向可用的手动同步，无需上架 App Store 或 CloudKit。文件仅包含已保存的开局树，不包含独立棋局库、整盘复盘文件、未保存研究或设备设置。文件大小上限为 50 MB；无效或不支持的版本在写入前拒绝。

## 棋局库

- 落子自动保存；保留初始 FEN、双方、结果、完整走法、备注、分析分支和回放位置。
- 重启恢复上次棋局。棋局与复盘以独立 JSON 文件保存在应用 Application Support 的 `QipanChess/Library` 目录；写入为原子操作，读取失败时保留原文件并显示错误。
- 棋盘下方支持首步、上一步、下一步、末步和指定着法跳转。回放不删除后续着法。
- 从过去局面走出新招，会保留完整原路线。可在棋局库选择保留路线；PGN 导出包含变例和注释。
- PGN 支持一盘棋、标准 SAN、紧凑回合编号、注释、NAG、嵌套变例、FEN 起始局面和结果；支持粘贴或 UTF-8 文件导入（集合文件 50 MB 上限，单盘仍为 2 MB）。批量导入会保留有效棋局并报告无法解析的条目。NAG 符号目前不保存。
- FEN 导入检查棋盘、王、易位权、吃过路兵状态和回合数。
- 棋盘升变可选后、车、象、马。将杀、逼和、常见确定子力不足、五次重复和七十五回合自动结束；三次重复／五十回合提供申请和棋。子力不足采用保守的确定规则，不枚举所有可能的死局。
- 切换自由分析与 AI 对弈保留棋局；“新对局”会另建记录。

## 自动评价与整盘复盘

实时评价固定使用深度 14，独立于 AI 难度和棋风；快速／标准／深入整盘复盘对应 10／14／18。最佳着与实战着均从同一个根局面、同一深度搜索，实战用 UCI `searchmoves` 限定根走法。保留初始 FEN 与走法历史，使引擎能识别重复局面。

预期得分使用 Stockfish WDL：`(胜 + 0.5 × 和) / (胜 + 和 + 负)`，从落子方视角计算。不能只使用胜率而忽略和棋。将杀使用确定的 1 或 0；缺少 WDL 的替代引擎使用百分兵值逻辑曲线估计。界面仍显示兵值方便阅读，但分类不按固定兵值损失。

| 标记 | 预期得分损失 |
| --- | --- |
| 最佳着 | 实战与根搜索首选一致 |
| 优秀 | 小于 0.02 |
| 好棋 | 0.02 至小于 0.05 |
| 不精确 | 0.05 至小于 0.10 |
| 错误 | 0.10 至小于 0.20 |
| 严重失误 | 0.20 及以上，或允许此前可避免的将杀 |

分档参考 [Chess.com 公开说明](https://support.chess.com/en/articles/8572705-how-are-moves-classified-what-is-a-blunder-or-brilliant-etc)。端点采用左闭右开。Stockfish WDL 针对引擎自我对弈，不能等同于 Chess.com 含玩家等级的预期得分模型；本地结果可能不同，不提供未经校准的玩家棋力或跨产品准确率。

- 关键好棋：首选较第二候选预期得分高至少 0.10，且不是唯一合法着或明显吃回。只使用同深度的第二候选。
- 妙着：短变化中真实投入非兵子力，加深四层后损失小于 0.02，局面不劣，其他候选并非已获胜。检查至少三半回合，普通吃回恢复子力的交换不会标记为弃子；仅覆盖可检测的短期牺牲，不能识别所有妙着。
- 理论着：本地开局库走法，只在评价仍属正面时采用。
- 错失机会：错过强制将杀且未保持取胜预期，或对手上一手明显失误后未保住胜势。
- 新走法自动排队评价；已经完成的共同前缀保留。快速连续走棋也会评价双方走法，分支切换会移除旧分支标记，取消后不发布旧任务结果。内嵌引擎可能需要完成当前搜索才能释放。
- 导入棋谱先评价当前步；可选择整盘复盘计算全部走法。每步显示解释、最佳／实战变化，可在自由分析试走最佳着并保留原路线。
- 图标共有十类，显示在棋谱和棋盘落点，可在“标记说明”中关闭棋盘标记。素材为 GPL 开源图标集改绘，来源与许可证见 `ThirdParty/MoveBadges/NOTICE.md`，不是 Chess.com 官方美术资源。
- v3 分类报告缓存采用新模型；旧版本报告保留在磁盘但不直接复用。评价曲线采用白方视角。

## 个人开局树

- 按收录终点的局势分为白方有利、黑方有利，同一分类内按初始局面与第一步合并；均衡或评分不足的路线单列。选择分类后直接在棋盘试走，系统按起始局面和第一步自动匹配树；保存时自动添加分枝，不同第一步自动新建树。悔棋、改线或切换分类都会重新匹配，同时保留当前试走路线。默认收录前 20 回合，可调整至 200 回合。自由分析与 AI 对弈继续自动收录绑定树，构建模式的草稿只在点击保存后写入树。
- 构建模式已有节点直接读取同引擎、同模型缓存，优先复用较深评分；已有但未评分节点保留待分析状态。只对新走法排队评分，不再同时运行局面分析，后台归档评分在构建模式让出资源。
- 暖白节点表示白方走法，深灰节点表示黑方走法。主线、备注、隐藏设置按白黑开局独立保存；来源信息仅用于内部去重，构建界面不显示来源棋局和推荐列表。
- 初始 FEN 与完整 UCI 前缀共同标识节点，转置保留不同路线，避免图中的循环。实战按棋局 ID 去重；研究分枝使用虚线，实战线宽随出现次数增加。
- 构建模式可修改树名、节点备注、主线顺序、收录范围，隐藏或恢复分枝。隐藏只改变展示，不删除棋局或研究来源；后续同步不会恢复隐藏路线。
- 选择节点后可修改这一步：回到前一步试走替代走法，保存时替换原分枝。默认删除保留选中步骤，清除其后的全部变化；也可连同当前步骤一起删除，或在树设置中删除整棵树。删除前备份至 `OpeningTrees/Trash`，界面可撤销上一次删除。资源同步不会恢复已删除的分枝或整棵树；明确保存路线或新建树时可再次收录。本地棋局不受影响。
- 三个模式共用候选着面板：一次 MultiPV=3 搜索，最多显示三个不同的当前行棋方走法，按排名附上本地质量标记，点击即可落子。构建模式按需获取，已有局面复用缓存。候选面板与棋盘不展示对手回应；引擎仍计算必要的抵抗。妙着不由排名直接推断，较差候选会如实标为失误。AI 应手保持 MultiPV=1，不再提供棋风选择。局面变化会取消过期建议，同一局面与深度的结果在当前会话缓存复用；浏览已有树不自动重复计算推荐。
- 折叠栏目整行均可点击展开。Mac 画布使用原生滚动位置，连续拖动从当前视野开始；只绘制可见节点，不创建整树的独立按钮。复盘结果缓存于内存，共同路线复用局面与走法文本。
- 画布从底部向上生长，支持滚动拖动、双指缩放、放大／缩小、适应全树与聚焦当前路线。节点显示 SAN 和质量图标，待评分节点显示虚线圆。
- 点击节点切换到独立研究棋局，原实战棋谱不被改写。自由分析仅显示当前共同路线附近的分枝；超过收录范围时显示树内已有的最深共同路线。
- 开局树与绑定独立保存在 `QipanChess/OpeningTrees`。旧训练偏好不再读取，但不会主动删除旧用户数据。

## 公开棋谱开局资源

公开用户名默认 `SuigennSennkakuGoodGirl`，可在“补充开局资源”中修改。拉取所有公开月份，串行请求，包含客户端标识、ETag/Last-Modified 缓存、429 退避与取消支持。网络断开时可读取已有缓存；404 或 403 会明确提示，PGN 导入可作为备用入口。参考 [官方 PubAPI 说明](https://support.chess.com/en/articles/9650547-what-is-the-pubapi-and-how-do-i-use-it)。

- 全部有效标准棋局保存到本地棋局库；变体与损坏棋谱单列提示。Chess.com Link 去重，不覆盖用户原有备注。无需账号密码，不读取私人分析。
- 全历史后台评分使用深度 14，逐步保存每手，重启可从连续已评分前缀继续。前台实时评价和 AI 思考期间不开始下一手后台搜索；正在进行的搜索可能需要完成后让出资源。暂停状态也会保存。
- 精彩发挥：本人至少 8 步，平均预期得分损失升序，其次妙着／关键好棋数量降序、日期降序。
- 复盘素材：包含明显失误或至少 0.05 单步损失，按本人最大损失、错误数量、日期排序。双方身份大小写不敏感，只计算本人走法，输赢不决定入选。
- 两类各最多 20 盘，按开局分组轮流选取；重叠棋局同时标记，注明具体入选原因。推荐数据保留为内部数据，构建面板不再展示棋局来源、推荐列表或入选原因。
- 全部有效棋谱用于积累开局资源；主题树按本人执棋方、初始局面与第一步走法合并。同为白方或同为黑方、以 d4 开始的路线进入各自的一棵树。旧树启动时自动合并，原文件与绑定先保存到 OpeningTrees/MigrationBackups；备注、隐藏状态、主线和较深评分保留，冲突主线作为节点备注记录。后续推荐只追加来源，不移除已有路线或覆盖自定义树名、备注和隐藏状态。
- 当前已实际读取并评分 93 盘公开快棋，产生 39 盘不重复推荐。数量是本次运行结果，之后同步会重新读取完整归档。

## 局势分类与资源整理

默认取每条路线前 40 个半回合（或更早的终点），采用 Stockfish 18、当前评分版本、深度至少 14 的完整评分。终点白方视角达到 +0.50 归白方有利，达到 −0.50 归黑方有利；其余或未完成分析的路线保留在“均衡／待评估”。分类依据路线终点，与原棋谱胜负、账号执棋方无关，也不表示该开局名称本身天然有利。

自动清理仅针对完整评分且至少 8 个半回合的导入路线：双方各至少两步预期得分损失达到 10 个百分点。个人研究和带备注的路线受保护。整理前在 `OpeningTrees/MigrationBackups/advantage-*` 备份全部树和绑定，`curation.json` 记录清理名单，后续同步不重新加入。原始棋局库与报告保留。

自由分析在桌面左侧直接展示树，窄屏提供树面板。棋盘上方的“摆棋”打开独立编辑界面：选择棋子后点格子放置、橡皮擦删除、清空或恢复初始局面，并可指定行棋方、易位权及 FEN。确认前不会改变当前棋局；应用时先保存原棋局，再创建新分析局面。无王、相邻双王、底线兵、与棋子位置不符的易位权等局面不能提交。
