# iPad 标注与布局修订（2026-10-04）

## 使用

在开局树面板选择当前树，点击「补齐缺失标注」计算尚无有效评分的步骤；「全部重算」更新当前树的全部分枝，包括隐藏分枝。共享步骤只计算一次，不恢复已删除的分枝。计算进度实时显示，已完成的标注自动保存，停止后可继续补齐。已有较深评分的步骤在重算时沿用其搜索深度。

电脑端「Stockfish 18」与平板端「Stockfish 18（内嵌）」的已有评分兼容，往返导入不再因为名称差异而丢失显示或重复补算。其他引擎版本仍独立处理。

局势走势跟随棋盘下方的一方：默认白方视角，反转棋盘后切换黑方视角。图上只显示已有棋步标注的彩色图标，无标注的位置保留曲线。右侧提供「上一步评价」。所有模式在落子后自动计算缺失的当前棋步评分，已有评分直接读取。等待评分时显示当前步数、走法与计算状态，不再展示旧步骤的评价。

iPad 中等宽度使用两栏并给右栏预留宽度；较宽横屏采用三栏。开局树构建模式亦限制各栏宽度，右侧内容可以纵向滚动。候选着区域保留高度，走势图和评价使用渐变过渡，整盘重算期间保留已有走势。
